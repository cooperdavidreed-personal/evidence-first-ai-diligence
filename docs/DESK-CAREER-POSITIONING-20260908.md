# Underwriting Desk — career demonstration

Category: underwriting change review, initially demonstrated through revenue-quality analysis for recurring-revenue businesses.

One sentence: Review how new evidence changes an investment case and prepare a consistent committee update, with deterministic calculations and explicit human judgment.

The product complements Excel and subscription-based AI assistants. It is a local synthetic/public-data demonstration, not a confidential enterprise deal room or a validated investment recommendation service.

## Defensible project description

Built a desktop-oriented PE/VC underwriting workbench connecting source-linked evidence, deterministic transaction scenarios, versioned deal review, governed MCP model proposals, supported Excel revision comparison, and committee materials. Implemented source/scenario consistency gates, human acceptance controls, durable local persistence and browser-tested revision workflows.

Native Claude and Excel checks were recorded before this increment; ChatGPT operation was user-confirmed. Current automated tests exercise the revised application and protocol. Cite the dated verification report when describing exact counts or native-client proof.

## Demonstration narrative

Start with an investment question. Show why an attractive headline measure can depend on a weak definition. Review a revised source. Explain the financial effect and the assumption connecting source evidence to economics. Show the human accepting or rejecting the treatment. Finish with a committee draft bound to the exact reviewed scenario, keeping unresolved diligence visible.

## Claims not established

No firm adoption, practitioner validation, realized returns, alpha, time-savings study, accounting assurance, authenticated committee approval, enterprise security certification or arbitrary-workbook modeling. Supporting a bounded source format does not equal parsing any data room. PE retained scenario reruns and general operating-package calculations have different supported mechanics.
