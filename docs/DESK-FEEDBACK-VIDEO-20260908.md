# Cooper's feedback walkthrough

Use the current local build at http://127.0.0.1:4198/?review=20260908-final#/. Open it in a full-width desktop browser, preferably 1440 pixels or wider; a narrow embedded panel will crop the desktop work area. The public Vercel release has not been changed by this implementation.

## Suggested 8–12 minute route

1. Deals: find AtlasGrid and open Brief. Say whether you can identify the view, the reason, and the next action without scrolling or help.
2. Brief: inspect the three investment drivers. Click Complete-cohort NRR. Does Evidence preserve the context you expected? Close the inspector and try Source files.
3. Model: compare selected terms and seller ask. Explore downside, then return to selected terms. Inspect Assumptions and fund policy only if needed.
4. Review: use Load example revision on the guided AtlasGrid case. Inspect the changed retention and economic consequence. This guided PE example uses a documented retained rerun, not arbitrary live PE modeling.
5. Diligence and proposals: open the relevant issue, inspect evidence, and note whether ownership and the question to resolve are clear. A model request uses selected evidence and the current review basis; the model cannot approve the investment.
6. Committee: read the preview, switch to Edit if needed, and inspect what prevents export or reconciliation. Rejecting or deferring the revision should not silently rewrite the investment memo.
7. For the general package flow: return to Deals → New deal → sample package → review mappings and approve the source baseline. In Model, expand Review a saved Excel model. Compare a revised supported workbook and prepare its source revision. Review/reject/accept remains explicit. Unsupported formula edits cannot use this shortcut.
8. Return to Deals and reopen saved work. Say whether the workspace feels like one coherent product.

Please narrate what you expected, where you hesitated, what information you could not find, and what felt redundant. A mistake or wrong click is useful evidence; do not rehearse it away.

- Linear: https://linear.app/features — compact task navigation, selected work items, clean status/action hierarchy. Workflow reference rather than an investing competitor.
- Quartr Pro: https://quartr.com/products/quartr-pro — financial-source presentation and reading surfaces. Compare the work area, not its marketing imagery.
- Carbon: https://carbondesignsystem.com/components/data-table/usage/ — table interaction reference already informing the implementation.

Three useful annotations: the screen I like most; the screen with the most unnecessary content; the one action I expected to be easier. No proprietary or confidential deal materials needed.

Then ask whether they would reopen the Desk on the next source delivery.
