# Underwriting Desk — Cooper Reed

Cooper Reed designed and built Underwriting Desk through Daily AI Agents to reduce reconstruction between financial evidence, AI analysis, diligence and committee materials. Its narrow proposition is a maintained investment case: what changed, what that means, which question now matters and which output needs attention.

The demonstration follows a fictional software company's monthly restatement. Revenue and EBITDA fall, cash drops below an analyst-owned minimum, and debt increases. The analyst can inspect the cells, record the liquidity question, mark the old conclusion contradicted and reconcile the partner update. The app does not pretend that a cash shortfall proves an investment decision.

The engineering choices support that workflow: original file preservation, confirmed financial definitions, local persistence, evidence cutoffs, deterministic arithmetic, source-scoped model access, proposal review and stale-output controls. A bundled desktop runtime reduces setup work without adding a Desk-operated inference service. AI assisted development; Cooper owns the product design, implementation decisions and evaluation.

A Python Decimal oracle checks 200 seeded arithmetic cases. Twelve frozen numeric citation fixtures exercise supported, contradicted and unsupported mappings. Browser and native package checks test the local path. These are engineering evidence; adoption and time savings await practitioner testing.
