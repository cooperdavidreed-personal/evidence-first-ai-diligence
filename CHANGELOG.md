# Changelog

All notable changes to this project are documented here.

## 0.2.0 — 2026-09-02 — Underwriting Desk practitioner-test candidate

- Unified prior Lab and Desk capabilities into one finance-native decision workspace.
- Added fail-closed Growth SaaS intake with an external Desk-owned policy profile and independent Northstar oracle.
- Added browser-local workspace persistence, portable state replay, human notes, diligence issue lifecycle, assumption review, memo editing, and exact evidence preview.
- Added bounded deterministic scenario controls and sensitivity views for retained and local cases.
- Added a same-origin hosted synthetic evidence-challenge adapter and named human proposal disposition, while preserving a read/proposal-only local MCP surface.
- Reworked partner PDFs, institutional interface, responsive behavior, and release documentation around a single Underwriting Desk identity.
- Practitioner results, real-deal validation, enterprise security, and investment outcomes remain unclaimed.
